# Contributing

Use Python 3.11 or later and a separate virtual environment. From the repository root, install `python -m pip install -e ".[test,mcp,a2a,claude]"` and run `python -m pytest`. Use a temporary `MHB_HOME` for manual experiments. Never submit transcripts, live Telegram identifiers, API keys, desktop session IDs, real mailbox databases or user configuration.

An adapter change should demonstrate a successful host acceptance, the result of a stopped or busy destination, and how it treats an ambiguous external outcome. For queue changes, test concurrent claims, both role stages, a cross-project lookup, and an idempotent replay. Use deterministic fixtures for unavailable services and label live validation separately. Include the OS, native host surface and version when reporting compatibility.
